# Graduation Project Management System (GPMS)

GPMS is a web-based system designed to help manage graduation projects in a clear and organized way.  
The system aims to reduce manual work and improve coordination between students, supervisors, and graduation project coordinators.

## Project Overview
Managing graduation projects using emails, meetings, and separate files can be confusing and time-consuming.  
GPMS provides a single platform to handle team creation, supervisor requests, progress tracking, and file submissions.

## Main Features
- User registration and authentication
- Student profile management (GPA, skills, interests)
- Team creation and invitations
- Supervisor request system
- Project phase tracking (Proposal, Progress, Final)
- Task management and file submission
- Dashboards for students, supervisors, and coordinators
- Notifications and meeting scheduling (planned for GP2)

## System Architecture
The system follows a layered architecture:
- Presentation Layer (Web UI)
- Application Layer (REST API Controllers)
- Business Logic Layer (Services)
- Data Access Layer (Entity Framework Core)
- Database (SQL Server)
- External Services (Email notifications)

## Technologies Used
- ASP.NET Core

- SQL Server
- JWT Authentication

- Postman (API Testing)
